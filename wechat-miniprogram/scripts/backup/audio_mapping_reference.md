## 文件名哈希规则

文件名格式: `{category}_{hash}.mp3`

其中 `hash` 是文本内容的 MD5 前 8 位：
```python
hash = md5(text.encode('utf-8')).hexdigest()[:8]
```

例如: `我饿了，想吃饭` → MD5 → `6fc93b8b...` → `daily_6fc93b8b.mp3`
