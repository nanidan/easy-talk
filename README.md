# 触音 - 失语辅助沟通助手（微信小程序）

## 📱 项目简介

「触音」是一款专为失语人群（中风失语、气管切开、喉部术后等）设计的微信小程序辅助沟通工具。围绕失语者的三类真实沟通场景设计：

- **应答**：对方提问（要喝水吗？疼吗？），患者点「是 / 不是」即可回答——这是失语沟通的基石，底部常驻超大按钮，任何页面一指即答
- **陈述**：预设高频短语 + 场景化分类 + 语音播报 + 大字显示，主动表达日常需求
- **呼救**：紧急短语自动循环大声播放，求助入口常显红色标识

**当前版本**：v2.2 - 围绕失语场景的深度优化

## 🚀 下载后怎么用（写给家属，不需要编程基础）

1. **下载本项目**：点上方绿色 `Code` 按钮 → `Download ZIP`，解压得到 `easy-talk` 文件夹
2. **安装[微信开发者工具](https://developers.weixin.qq.com/miniprogram/dev/devtools/download.html)**（免费，选稳定版），打开后选「导入」，目录选解压出来的 `easy-talk` 文件夹，AppID 可先选「测试号」体验
3. **手机上用**：工具里点「预览」扫码就能在手机上打开；要长期使用，注册一个小程序账号后点「上传」发布成自己的小程序

**想换成自己家人常用的短语？** 用任意文本编辑器打开 `pages/index/index.js`，搜索 `SCENES`，把引号里的短语改成你需要的，保存即可。
提醒：自己新加的短语没有预合成语音，点击后只有大字显示；想给它配语音，看下方「语音生成」章节——阿里云新用户的免费额度足够本项目使用。

## ✨ 核心功能

### ✅ 是/否应答（最高频）
- 底部常驻「不是 / 是」超大按钮（120rpx 高），任何页面都能一指即答
- 点击后全屏闪现超大"是/不是"，1.6 秒自动消失，不打断当前操作
- 对方提问时，患者指一下按钮即完成一次沟通

### 🕐 最近使用
- 自动记录最近表达的短语，各场景页顶部常驻展示（最多 4 条）
- 失语者表达高度重复——最近说的就是最常说的，无需翻找
- 求助页保持极简，不显示

### 🎯 场景化短语分类（7 个标签，两行展示）
- **🏠 日常**：吃饭、喝水、休息、身体感受
- **🆘 求助**：紧急呼救（第一条自动循环大声播放）、叫救护车、报警（排在第二位并常显红色标识）
- **🏥 医疗**：疼痛、症状、就医相关
- **🛒 购物**：问价、支付、退换货
- **🚌 出行**：问路、求助、交通相关
- **😊 情绪**：心情、社交、需求表达
- **⭐ 收藏**：自定义短语与收藏短语集中管理

### 🔊 语音播报
- **离线语音**：预合成音频，无需网络，即时响应
- **双语言支持**：普通话（xiaoyun）+ 粤语（jiajia），设置面板中选择，自动记忆
- **循环播放**：大字显示时可重复播放（1秒间隔）；紧急短语自动循环
- **语速可调**：慢 / 正常 / 快三档

### 🎨 大字显示模式
- 全屏大字展示，方便对方阅读
- 点击空白处关闭
- 循环播放按钮

### ⭐ 收藏
- 任意页面长按短语即可加入/取消收藏
- 已收藏短语卡片右上角带 ⭐ 角标，一眼可辨
- 收藏页长按可取消收藏

### ♿ 无障碍
- 字号三档可调（标准 / 大 / 超大），覆盖全部界面包括应答按钮
- 高对比度模式（深色背景 + 高亮文字）
- 触控目标大，关键操作带震动反馈

## 🔊 语音生成（阿里云 TTS 免费获取）

小程序的短语音频通过阿里云「智能语音交互」的语音合成（TTS）预生成。**新用户有 3 个月免费试用，语音合成按合成字数计量**——本项目全部短语两套语言合计不足 1000 字，一次生成远在免费额度内，不产生费用。

### 第一步：开通免费服务（约 5 分钟）

1. 注册/登录 [阿里云](https://www.aliyun.com/)（需实名认证）
2. 进入 [智能语音交互产品页](https://www.aliyun.com/product/nls)，开通服务时选择**免费试用版**（试用期 3 个月，到期前生成的音频文件可永久使用，不受试用期影响）
3. 进入 [智能语音交互控制台](https://nls-portal.console.aliyun.com/)，点击**创建项目**，勾选「语音合成」能力，记下项目的 **AppKey**
   - 普通话音色（如 xiaoyun 小云）和粤语音色（jiajia 佳佳）需要分别创建支持对应音色的项目，各有一个 AppKey

### 第二步：获取 AccessKey

1. 控制台右上角头像 → **AccessKey 管理** → 创建 AccessKey，得到 **AccessKey ID** 和 **AccessKey Secret**
2. 建议使用 RAM 子账号并只授予智能语音交互权限，不要用主账号 Key
3. ⚠️ AccessKey 只通过环境变量传入，**不要写进代码或文档提交到仓库**

### 第三步：生成音频

脚本用 Python 标准库，无需安装依赖。推荐"方式2"（AccessKey 自动换取 24 小时有效的 Token，不用手动 curl）：

```bash
cd scripts

# 生成普通话（xiaoyun 小云，标准女声）
export ALIYUN_ACCESS_KEY_ID="你的AccessKeyId"
export ALIYUN_ACCESS_KEY_SECRET="你的AccessKeySecret"
export ALIYUN_APPKEY="普通话项目的AppKey"
python3 generate_tts.py --output base --voice xiaoyun

# 生成粤语（jiajia 佳佳，粤语女声）
export ALIYUN_APPKEY="粤语项目的AppKey"
python3 generate_tts.py --output cantonese --voice jiajia
```

Windows PowerShell 把 `export` 换成 `$env:`（如 `$env:ALIYUN_APPKEY="..."`）。

生成结果：
- `assets/audio/base/`、`assets/audio/cantonese/` 下的 mp3 文件
- `assets/audio/audio_map_base.json`、`audio_map_cantonese.json` 短语→文件的映射表

先用 `python3 generate_tts.py --test` 可以只合成一条验证配置是否正确。

### 第四步：接入小程序（关键，别手抄）

小程序实际读取的映射在 `utils/audio_manager.js` 的 `AUDIO_MAP` 中（小程序内无法用 wx.request 读包内 json，所以 json 只是同步源）。**新增或重新生成音频后，必须把 `audio_map_base.json` 里的对应条目复制进 `AUDIO_MAP`**——请整行复制粘贴，不要手敲文件名：曾因手抄 hash 差一个字符（9c5354eb → 9c9354eb），导致「请帮我包起来」无声。

### 给新短语补音频的完整流程

1. 在 `scripts/generate_tts.py` 的 `PHRASES` 对应分类里加入新短语
2. 重新跑第三步命令（脚本会为所有短语重新生成，已存在的会覆盖为同名新文件）
3. 打开 `assets/audio/audio_map_base.json`，把新短语的整行条目复制进 `utils/audio_manager.js` 的 `AUDIO_MAP`
4. 跑 `node scripts/test_static_checks.js`，它会逐条核对映射与磁盘文件一致，能兜住路径抄错

详细参数（音量/语速/音调/采样率）与常见报错见 [scripts/README.md](scripts/README.md)。
